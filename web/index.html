THERMOSTAT SETUP

Create an SD-card image

On the thermostat, open About and enter the firmware version shown beside Firmware. The image includes the matching version stub and this server's public root CA.

Write the downloaded image to an SD card with Rufus or a similar disk-image tool. Writing an image erases the selected card. On the thermostat, choose SD Card → Import/Export and import Custom Images only. Cancel any firmware upgrade prompt.

NEW INSTALLATION

Generate new credentials

Create a unique root CA and matching server certificate. Create an SD-card image below to import the public CA on your thermostats.

Credentials are saved in the add-on's persistent storage. Starting or updating the add-on never generates another CA.

EXISTING INSTALLATION

Upload your working pair

Migrating an existing server? Use its current certificate chain, matching private key, and the same public root CA already trusted by your thermostats.

The root CA must match the server chain and be trusted by the thermostats. If this is a new CA, create an SD-card image above and import it to each thermostat. Never upload the root CA's private key.
