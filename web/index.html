OPTIONAL · EXISTING INSTALLATION

Upload your working pair

Migrating an existing server? Use its current certificate chain, matching private key, and the same public root CA already trusted by your thermostats.

The root CA must match the server chain and be trusted by the thermostats. If this is a new CA, create an SD-card image below and import it to each thermostat. Never upload the root CA's private key.

THERMOSTAT SETUP

Download SD-card image

On the thermostat, open About and enter the firmware version shown beside Firmware. The image includes the matching version stub and this server's public root CA.

  1. Write the downloaded .img file to an SD card with Rufus or another disk-image writer. Choose DD Image mode if prompted. Writing the image erases the selected card.
  2. Insert the card into the thermostat. Open SD Card → Import/Export and import Custom Images only. If prompted to update firmware, cancel: this image imports the Skyport public root CA and does not install firmware.
  3. Remove the card and restart the thermostat so it reloads the root CA. Restart from Menu → Settings → Installation Settings → Restart Thermostat, or remove the thermostat from its base and reinstall it.
